### Hotfix — on-device SwiftData crash in the collection store — 2026-07-21
`MovieCollectionLocalDataSourceImpl.fetchAll()` used `FetchDescriptor(sortBy: [SortDescriptor(\.addedAt, order: .reverse)])` on the GENERIC `Model: CollectionMovieModel`. On iOS this traps every call ("Couldn't find \FavoriteMovie.<computed …(Date)>") because `\Model.addedAt` resolves to a protocol-witness (computed) keypath SwiftData can't match to the concrete stored property → favorites/watchlist reads crashed the app. The macOS host test runner TOLERATED the bad keypath, so `CollectionIntegrationTests.recencyOrderFromRealStore` passed and hid it; the app's iOS UI tests use `StubFavoritesRepository`, so nothing exercised the real generic source on iOS. FIX: drop the SwiftData sort — `fetchAll()` is now an unsorted `FetchDescriptor<Model>()` and `all()` sorts in Swift (`sorted { $0.addedAt > $1.addedAt }`), the platform-independent "fetch-and-filter in Swift" pattern this file already espoused. REGRESSION GUARD: new `TMDBTests/CollectionLocalStoreRegressionTests` drives the REAL `FavoritesRepositoryImpl` against an in-memory container and runs on the **iOS simulator** (unlike the macOS-host package tests) — reintroducing a SwiftData-level sort now traps that run. Verified: the iOS regression test + 262 package tests + lint green. LESSON: SwiftData behavior differs macOS-host vs iOS; anything touching the real container needs an iOS-executed (app-target) test, not just a package test.

### Networking enhancement — request/response logging (decorator) — 2026-07-21
`LoggingAPIClient` (Networking) is an `APIClient` DECORATOR — same protocol, wraps another client, delegates to it — that logs each request (📤 method + path + query, with a 🧩 body) and response (📥 ✅ type/bytes + ⏱ duration; ❌ on error, 🚫 on cancel) through the CoreUtilities `AppLogger`. SECRETS ARE NEVER LOGGED: the Bearer token is added by an interceptor INSIDE the wrapped client (invisible to the decorator), and sensitive query/body keys (`session_id`, `guest_session_id`, `api_key`, `request_token`, `access_token`, `authorization`) are redacted to `•••`. Wired in the composition root ONLY for Dev/Test (`makeAPIClient` switches on `environment.name`; Staging/Live get the bare client). Injectable log sink for testability — 4 tests (delegation, request+response emojis, query+body redaction, error rethrow).
